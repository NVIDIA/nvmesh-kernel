Diagrams

In order to view those diagrams you need to install [draw.io](https://github.com/jgraph/drawio-desktop/releases/tag/v28.2.8) tools.

draw.io tool has multiple advantages. One of them, it is possible to store any diagram into "png" graphical file format and embed the diagram inside.
